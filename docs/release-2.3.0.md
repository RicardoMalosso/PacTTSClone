# PacTTSClone 2.3.0

- TTS Tourney defaults to single elimination with optional Twitch polls and host picks.
- Random drafts draw 4, 8, 16, 32, or 64 clips and favor clips with fewer previous appearances.
- Brackets and side-by-side matchups show voice pictures, win/loss records, and medals.
- Terrible horrible tags exclude clips from future random drafts while leaving current matchups intact.
- Fixed pending OBS playback getting hidden behind history and diagnostic write errors stopping generation.

This release ships as an application update. Existing installations can check Configuration → Application updates and restart to apply it.
