# PacTTSClone RC7

Speech generation requires NVIDIA CUDA; CPU transcription and audio processing remain. No CPU fallback. Includes CUDA worker restart, status, per-generation VRAM logs and advisory low-memory alerts.

Local generation and OBS share the final Local tab. Saved Twitch cards provide pause/resume, OBS links and collapsible queues without selecting a channel. IRC stays active alongside optional authorized events. Reward creation and editing expose native cooldown and redemption limits.

Setup hides when healthy, with a Configuration toggle to reveal it. Existing compatible installer environments, cached packages and verified model files are reused. Different installation folders require selecting/importing previous data; missing or invalid files may download again.

This unsigned Windows installer is validated on hosted Windows runners. Automated inference/Twitch tests use simulated engines/events; no real gaming/GPU benchmark, live paid-event acceptance or code-signing claim.
