# PacTTSClone 2.3.0-rc.6 — TTS Tourney

- Compare existing generated MP3s in the local **TTS Tourney** tab and review head-to-head results and rankings.
- Pick from Today, Last week, a date range, Previous Winners, or All.
- Start optional Twitch polls for matchups. Your local choice determines the result.
- One local report removes a clip from its tournament and marks it **shit from a butt**.
- The mode picker includes **Community Voting (INDEV)**, which requires public voting.
