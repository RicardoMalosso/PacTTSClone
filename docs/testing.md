# Verification — v0.2

## Deterministic suites

```
python -m pip install -e '.[dev,browser]'
python -m pytest -q
python -m ruff check .
python -m playwright install chromium
python -m pytest tests/browser --browser chromium -q
```

Core tests include real FFmpeg decoding/encoding, SQLite persistence, startup
recovery, bounds/validation, configuration, saved voices/transcripts/thumbnails,
moderation-before-render, custom terms/Unicode/cooldowns, native-hotkey message-loop
simulation, IRC framing/PING/reconnect/deduplication, FIFO/countdown/cancel/replay,
coordinator/mirror leases and per-stage logs. An actual spawned fake-engine worker
is killed mid-generation, then a new process successfully completes another job.
This proves process lifecycle/cancellation, not real voice quality or GPU behavior.

Browser tests use actual Chromium with explicit fake inference engines: original
upload/player/download flow; saved voices, transcription and settings; timer and
cancel controls; channel configuration/moderation/countdown/replay; locale detection
and override across tabs/reloads; speech-language persistence; existing channel
command dropdown refresh after voice preparation without losing drafts; sharing controls; remote admin/OBS cookie bootstrap; backend panic
stopping browser audio. Public-origin tests emulate cloudflared forwarding in the
browser and enforce actual server capability checks; they do not claim an external
internet tunnel was established. Keep in-flight browser routes drained during
teardown so a context closure does not poison the next test.

Every deterministic test has a 60 s timeout; CI core has a 15 s per-test and 3 min
step timeout. Never use large binary values as autogenerated parameter IDs. The
20 MiB fixture has the explicit ID over-20MiB. CI tests Windows/Linux Python
3.11/3.12 and Chromium on Linux, plus wheel build and PowerShell syntax on Windows.

## Real model

Install matching PyTorch and `.[inference]`. Example:

```
pacttsclone-smoke --device cpu --reference reference.mp3 --ref-text "Exact reference transcript." --text "Olá, bom dia."
```

The smoke now uses the production spawned worker. A separate preset smoke creates
a voice with blank transcript, waits for real local ASR, then generates from the
saved voice and verifies that the speech job has no second transcribe stage.
Record hardware/thread count, phase wall/CPU time, RAM, model and outcome; inspect
MP3 format with FFprobe. Perceptual quality and performance on the user's hardware
require separate listening/benchmarking, not assertions against a fake model.

## External integration and hardware

Verify the official cloudflared release asset digest and installed CLI flags.
A real public Quick Tunnel additionally requires DNS/outbound Cloudflare access;
record environment network failures separately from app test failures. Twitch's
actual anonymous WSS handshake likewise needs outbound network access. Deterministic
IRC tests use a fake socket, including reconnection; do not mislabel them live IRC.

A physical Windows global keypress (including while a game is focused), real OBS
CEF source and GTX 1660 SUPER VRAM/latency are manual/hardware acceptance items.
Native message-loop simulation and Windows CI cover code paths but do not establish
physical-key delivery or GPU compatibility.

Console-interrupt regression uses a real spawned test engine: verifies SIGINT is
ignored before initialization, raises SIGINT in that child on Windows/POSIX, and
on POSIX also delivers SIGINT while it waits for the next command. A second job
must reuse that PID, then sentinel shutdown must exit with code zero. Existing
hard cancellation/recovery tests still run. This is not a physical Windows console
keypress test.

## Windows installer preview

`.github/workflows/installer.yml` compiles `installer/setup.iss` on Windows and
asserts the unsigned bootstrap is below 10 MiB. PowerShell 5.1 helpers are executed
with controlled download responses to verify retries, corrupt-cache rejection,
partial cleanup and non-overlapping app/data paths. A separate real network smoke
installs the actual CPU dependency stack, starts the installed HTTP launcher,
repeats setup and uninstalls while retaining a user-data marker. Logs/artifacts
are retained. This smoke does not download model weights, simulate CUDA hardware
or establish cloning quality. Only a passing installer job may create a draft
prerelease; no published release or signing claim is generated automatically.

## RC4 contained-root layout and failure navigation

The selected destination is now a container: private app/runtime/launcher/config
files live in root/app, default recordings/models/caches live in root/data, and
launch/uninstall shortcuts live at root. The bootstrap still enforces non-overlap
between the private app directory and data. Existing custom data paths are retained;
no silent relocation/deletion of old data or legacy installation files.

Removed the unsafe global Next button reset from CurPageChanged. Only the intro
countdown may control its button. Preparation failure explicitly clears NeedsRestart,
blocks advancing the error page, offers Open setup log and saves a fallback log
for errors before PowerShell transcript initialization. Inno restart requests are
disabled and the finish-page restart choice is set to No/disabled. Failure tests use
/NORESTART as additional test-runner protection; no real reboot is attempted.

Windows tests cover the new contained data path, explicit failure before downloads,
disabled Next/Finish and log availability, plus real installation, root shortcut
startup and uninstall preserving data. Validation is pending the RC4 workflow.


## RC4 mandatory browser setup

Current design supersedes earlier installer dependency/model-on-first-use notes:
native setup contains no CUDA/PyTorch. Initial Setup is the first required web tab;
it installs CPU/NVIDIA inference packages and verified OmniVoice/Whisper files,
shows download/cache/resume activity and unlocks generation only on success.
Worker uses local offline model directories afterward. Package activity has no
fabricated byte total. Owner-only API supports cancel/retry/logs. See
[web setup design](web-setup-design.md) and [installer design](installer-design.md).
Validation pending RC4 Windows workflow; backend/browser results recorded below
when completed. An automatic updater is not implemented.

OBS player/control links open in a new tab with noopener/noreferrer. Channel link
nodes remain stable during polling so a refresh between mousedown/mouseup cannot
swallow the click. Browser acceptance covers actual popup URLs for both channel
and general playback/control links.

Generation monitoring follows the server's active job, independently of local form
submission. A compact source/stage/timer/cancel strip remains visible across tabs;
the full Generate monitor follows Twitch, preparation and queued local requests,
including after reload. It prioritizes the running job over later queued work.
Cancel targets the displayed job. Monitoring remote requests never autoplays them
in the admin browser; OBS retains playback responsibility.
