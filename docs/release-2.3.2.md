# PacTTSClone 2.3.2

Type `!pactts` in Twitch chat to list the channel's voice commands, aliases, enabled sound effects and active engine's vocal tags. Long lists arrive in complete entries with at least two seconds between messages.

In **Twitch & OBS**, edit the channel, enable Twitch events and save. Select **Reply to !pactts with available voices and SFX**, then **Connect Twitch account** to grant the broadcaster chat-writing permission.

Existing installations receive this application update through the auto-updater.
