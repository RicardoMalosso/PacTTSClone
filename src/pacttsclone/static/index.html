GPU = graphics card; VRAM = its dedicated memory. CPU = main processor; RAM = system memory. Whisper transcription runs on CPU in all modes. AMD/Intel/Apple GPU backends are not implemented.

Panic stops current/countdown audio and pauses channels. Resume playback in Twitch & OBS. It works outside the browser on Windows when the shortcut is registered successfully.

CPU seconds count time across worker threads and can exceed elapsed seconds. GPU stage/stream time includes CPU coordination and is not an exact GPU-busy counter. Unknown measurements appear as N/A.
