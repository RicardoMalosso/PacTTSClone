Import stuff (optional)

Import model weights from a previous installation
Search known PacTTSClone and Hugging Face folders, plus optional old folders below. Only model weights of at least 64 MiB are considered. Configurations and settings are not imported. Setup reuses a file only when its size and SHA-256 match the pinned model revision.
Only matching large weights are imported. When Move is checked, originals in the folders you entered are removed only after the new weight copies verify. Other old data is untouched. Shared caches found automatically are copied. The old installation may need to download moved weights again.
Import configuration, voices and outputs
Personal data is copied; the old folder is kept. Existing voices, audio and channel settings are preserved. Imported channels start disconnected and paused. Twitch credentials, caches and pending playback are not imported.
